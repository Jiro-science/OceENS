# `course-2026` becomes the default branch for the semester

For the 2026–27 *Complex Web Services* course, around twenty students fork OcéEns and work from the default branch, so `course-2026` becomes the repository's default branch: forks start from it and pull requests target it (including the development login, #82, and the per-role seed, #84). `main` is left untouched during the semester, to give students a stable base and to keep course-specific code out of it; no `main` → `course-2026` synchronisation is planned before the end of the semester.
